# Answering User Questions

- Wenn der User nach einer Antwort noch einmal nachfragt, lies die Referenzen, auf die du dich in deiner Antwort beziehst, noch einmal nach und gebe sie in deiner Antwort als Belege aus. Damit soll verhindert werden, dass du dich auf veraltete oder gecachte Dokumente beziehst.
